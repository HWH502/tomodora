# 🍅 番茄鐘

一個會養寵物的番茄鐘網頁 App。

專心工作 25 分鐘、休息一下，這是一般的番茄鐘。這個 App 多了一件事：你每完成一個工作時段，就會賺到金錢和技能點，還能養一隻寵物（狗或貓，各 3 個品種）——牠會隨著你累積的專注時間慢慢長大，需要你買東西照顧牠，也可能因為疏於照顧而離開。

## 功能

- 可自訂工作／短休息／長休息時長的番茄鐘，完成會有音效與系統通知提醒
- 養一隻寵物，隨專注時間累積成長，有飽食度、潔淨度、健康度、好感度需要照顧
- 商店可以買玩具、飼料等道具，一次性道具會實際對寵物產生加成效果
- 飼主技能樹，把累積的技能點拿去點各種對飼養有幫助的加成
- 專注成效統計頁面：熱力圖、週／月趨勢圖，記錄你的專注軌跡
- 存檔可以匯出成檔案備份，或匯入還原、換裝置使用
- 完全在瀏覽器本機運作，不需要帳號、不需要伺服器，資料存在你自己的瀏覽器裡

## 開發

需要 Node.js。

```bash
npm install
npm run dev     # 啟動開發伺服器
npm test        # 跑自動化測試
npm run build   # 打包
```

## 技術

React + Vite 打造，沒有後端，所有設定與進度都存在瀏覽器的 localStorage（部分資料使用 IndexedDB）裡。
